# DeepSeek 面试助手 · 下载页

> 这个仓库**只用来放安装包**，源码不在这里（源码是私有的）。

一个用**你自己的 DeepSeek API Key** 驱动的面试 / 笔试辅助浮层（Windows）。
没有会员费、没有积分、没有中间服务器 —— 题目直接从你的电脑发到 `api.deepseek.com`，
答案直接回到你屏幕上。

```
按 Ctrl+Alt+Q  →  框选题目  →  松手  →  答案流式出现在浮层里
```

## 本次更新（v1.1 · 2026-10-11）

> **建议 v1.0 用户更新。** 修掉的两个问题都不是偶发。

| 修的问题 | 说明 |
|---|---|
| **发了截图什么答案都没有** | 旧版"关思考"靠省略字段，而这个模型默认开思考，于是把 5000 token 预算全烧在思考上、正文 0 字 —— 而且被当成"成功"，你连报错都看不到。现在显式关掉：同题 **0 字 / 27.7 秒 / ≈¥0.0201** → **3790 字 / 7.9 秒 / ≈¥0.0070** |
| **程序突然消失，事后查不到** | `pythonw` 没有控制台，所有异常都被扔掉。现在 `data\crash.log` 会记下崩溃时**所有线程**的调用栈，另有心跳文件和"上次是否正常退出"标记 |
| **健壮性** | 拆掉一个嵌套事件循环的隐患；40ms 心跳不再可能中途停摆；空正文不再被当成"完成"写进历史 |

完整清单见 **[CHANGELOG.md](CHANGELOG.md)**。

**升级方式**：下载新包解压覆盖。如果 `data\config.ini`（API Key / 简历 / JD / 题库）
在解压目录里，先备份出来；新版本会自动补上新增的配置项。

## 快速开始（3 步）

1. **解压**到一个你找得到的目录
   （别放 `C:\Program Files` —— 那里程序写不了自己的数据）
2. **双击 `静默启动.vbs`**
3. 程序会让你填 **API Key** → 去 <https://platform.deepseek.com> 申请，充一点额度

填完就能用了：按 `Ctrl+Alt+Q`，框选题目，松手出答案。

> 第一次用建议点开「面试上下文」，把你的**简历和岗位 JD** 贴进去 ——
> 答案会明显更贴合你的真实经历，而不是泛泛而谈。

## 主要功能

| 功能 | 说明 |
|---|---|
| **框选题目即出答案** | `Ctrl+Alt+Q` 拖框 → 模型视觉识别 → 答案流式显示 |
| **窗口对录屏/共享不可见** | Windows 官方 `WDA_EXCLUDEFROMCAPTURE`；已用 ffmpeg 真录实测（82.8% → 0.0%）。主浮层和所有弹窗都生效 |
| **手机扫码看答案** | 电脑自建局域网服务，数据**不出内网**。手机连上后电脑界面自动收起，手机退出观看自动恢复 |
| **手机远程 / 自动截屏** | 不碰电脑就能发起解答；自动模式**只在画面真的换题时**才问模型，不白烧额度 |
| **本地语音识别** | sherpa-onnx + SenseVoice 在本机跑，**音频不上传**。实测 RTF 0.023 |
| **简历 / JD / 定制题库** | 全部拼进系统提示词，不走向量检索 |
| **双模型热键切换** | `deepseek-flash` / `deepseek-v4-pro` |
| **离线自检 176 项** | 双击 `自检.bat`，不消耗 API 额度 |

**成本参考**：一次全屏截图问答实测约 **¥0.004**（输入 972 + 输出 783 token，
DeepSeek 空闲时段半价）。v1.0 因为会在思考上白烧预算，同样的题实际要 ≈¥0.02。

## 出问题怎么办

| 情况 | 做什么 |
|---|---|
| 双击没反应 / 打不开 | 双击 **`自检.bat`** —— 环境诊断 + 离线自检，结论直接显示 |
| 想看日志 | `data\launch.log`（启动）和 `data\app.log`（运行） |
| **程序突然消失了** | 看 `data\crash.log`（崩溃时所有线程的调用栈）和 `data\lastbeat.txt`（最后活着的时刻）。下次启动也会在 `data\app.log` 里写明"上次没有正常退出" |
| **发了截图没有答案** | v1.1 已修。若仍出现，界面会直接说明原因（多半是思考吃掉了输出预算） |
| 窗口找不到了 / 退不掉 | `python 停止.py`，或 `python 停止.py --status` 只看状态 |
| 提示缺库 | `启动.py` 会给出具体命令；依赖已内含，通常不会遇到 |

## ⚠️ 使用前请读这一段

**这是正当用法**：面试复盘、模拟练习、查漏补缺、开卷环境下的效率提升。

**这些风险你自己承担**：用于**明确禁止 AI 辅助的监考笔试或面试**。

**本程序明确不做的事**：

* 不装内核驱动、不拦截键盘、不做网络层反检测
* 不针对任何特定监考系统做规避
* 不做人工代做、不做虚拟机绕防护

**反捕获的边界**（别误解）：

* 只对**软件捕获**有效（录屏、屏幕共享、截图工具）
* **手机拍屏、旁人旁观 100% 看得到** —— 这是物理层面，任何 API 都挡不住
* 内核驱动级的采集可能不受约束

**手机同步的注意事项**：

* 二维码里是一个**有效令牌**，扫完请把二维码窗口收起来
  （程序默认会在手机连上 6 秒后自动收起）
* 手机端**不需要密码**，只靠那个令牌 —— 别把二维码给不该看的人
